# Основы машинного обучения

Обучающее веб-приложение КГТУ им. И. Раззакова (Бишкек): 10 лекций, тесты, 3 интерактивные демонстрации и лабораторные работы.

Стек: React 18, Vite. Бэкенда нет, прогресс хранится в браузере (localStorage).

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/ (один index.html)
```

## Структура

- `src/config.js` — название университета, логотип и фото для карточек на главной
- `src/Landing.jsx`, `src/landing.css` — главная страница с анимацией
- `src/App.jsx` — курс: лекции, практика, тесты
- `src/Demos.jsx` — демо: kNN, порог классификации, k-средних
- `src/data.js` — вопросы тестов и названия лекций
- `src/lectures.json`, `src/labs.json` — тексты лекций и лабораторных (HTML из исходных .docx)

## Публикация на GitHub Pages

В репозитории: Settings → Pages → Source: GitHub Actions. После каждого push в ветку `main` сайт собирается и публикуется автоматически (`.github/workflows/deploy.yml`).
